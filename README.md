# ITBDA Project 2

This project applies big data and text-mining techniques to four tasks using Java, R, web data and PostgreSQL.

## Project tasks

1. **MapReduce:** Find the row and column positions of a keyword in documents.
2. **LDA topic modelling:** Identify themes in South African news articles using R.
3. **Web text mining:** Collect, clean and summarise text from a NASA article.
4. **ETL and PostgreSQL:** Scrape book records, clean the data in R, and analyse it using SQL.

## Main files

- `ITBDA_Project_1.ipynb` — Question 1 notebook.
- `ITBDA_Project2_Question2.R` — Question 2 R script.
- `ITBDA_Project2_Question3.R` — Question 3 R script.
- `ITBDA_Project2_Question4.R` — Question 4 R script.
- `books_raw.csv` — scraped book data before cleaning.
- `books_clean.csv` — cleaned book data used for analysis.

## Data sources

- Question 3: NASA Science article on Earth's changing atmosphere.
- Question 4: [Books to Scrape](https://books.toscrape.com/), a practice website for web scraping.

The book prices and ratings are used to demonstrate the ETL workflow and should not be treated as current market information.

## Tools

Java, R, PostgreSQL and SQL.
